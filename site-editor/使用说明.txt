课题组主页编辑器 — 使用说明
================================

一、启动
  双击「启动编辑器.bat」，浏览器会自动打开 http://127.0.0.1:8765
  （或直接用浏览器打开 editor.html，也可以用，但功能受限，建议用 bat 启动）

二、编辑器包含 6 个页面
  1. 个人信息        — 姓名、职称、单位、课题组名称（如 Pho-FreeU Lab，
                       显示在导航栏/首页/页脚）、Email、照片、About Me（富文本）、
                       Services、Education（可增删改、上下移动）
  2. Group Members   — 在读成员 / 已毕业成员两组，每位成员可：
                       · 上传照片、编辑姓名/学位/年级/去向
                       · 勾选「启用独立个人主页」
                       · 【上传 Word 生成主页】—— .docx 会自动转换成网页
                         （支持标题、加粗、列表、链接、图片，图片自动入库）
                       · 手动编辑主页内容、预览生成效果
  3. Publications    — 期刊 / 会议 / 专利三类论文：
                       · 快速添加：粘贴标题 + 链接即可
                       · 每条可编辑作者、年份、卷期、备注、链接
                       · 可删除、上下移动，导出时自动按年份分组
                       · ⭐ 亮点展示：点击列表中的星标或编辑弹窗勾选，
                         可为论文配置：
                           - 创新点说明（卡片上显示的一句话介绍）
                           - 配图：🌐「从论文链接抓取」自动读取论文页面
                             配图（og:image，Nature/Science Direct 等多数
                             出版商可用；失败时用 📤 手动上传截图）
                           - 补充链接（Code / 数据集 / 项目主页等）
                         设为亮点后，Publications 页顶部会出现
                         "Research Highlights" 图文卡片展示区
  4. Honors and Awards — 每行一条荣誉，直接改文字即可
  5. Related Codes   — 代码/项目页链接，支持直接粘贴 URL
  6. 发布导出        — 一键生成完整静态网站

三、生成网站（部署到本文件夹）
  点「发布导出」→「生成 / 更新网站」，
  新架构网站直接部署在： C:\个人课题组主页\（本文件夹即网站根目录）
    index.html          个人信息（About / Education / Services）
    members.html        团队成员
    publications.html   论文（期刊按年份分组 / 会议按方向分组 / 专利）
    honors.html         荣誉奖项
    codes.html          代码链接
    members\*.html      每位启用了个人主页的成员的独立页面
    photos\             所有照片
  顶部导航栏把五个页面互相串联，成员卡片可跳转到其个人主页。
  原 index.html 已自动备份到 备份\index_原版备份_2026-09-27.html

四、一键发布到 GitHub Pages
  「发布导出」页下半部分：
  1. 填写 GitHub 用户名（仓库名留空 = 用户名.github.io，即个人主页地址）
  2. 点「一键发布到 GitHub」→ 首次会【询问是否进行账号授权】：
     · 点「打开令牌创建页」（已预选 repo 权限）→ Generate token
     · 复制 ghp_ 开头的令牌粘贴回来 → 保存授权
  3. 之后每次发布只需点一下按钮：自动 构建 → git 提交 → 创建仓库(如需)
     → 推送 → 开启 GitHub Pages，完成后显示线上地址
  · 令牌只保存在本机 site-editor\github_config.json（已被 .gitignore 排除，
    不会进入仓库）；不勾选「记住令牌」则仅本次会话有效
  · 若远程仓库已有不同历史导致推送被拒，勾选「强制覆盖远程」后重试
  · 首次发布后约 1-2 分钟，即可访问 https://用户名.github.io

四、数据安全
  · 所有编辑实时保存到 site-editor\data.json（并自动备份 .bak）
  · 原来的 index.html / photos 目录不会被改动
  · 「导出数据」可下载 JSON 备份；「导入数据」可恢复
  · 「恢复初始内容」可一键回到从原主页解析出的初始状态

五、常见问题
  · Word 转换失败？请确认文件是 .docx 格式（.doc 请先用 Word 另存为 .docx）
  · 浏览器本地模式下 Word 解析和网站导出不可用，请用 bat 启动本地服务
  · 端口被占用？把 editor_server.py 里的 PORT = 8765 改成其他数字
